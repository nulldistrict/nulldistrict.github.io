# Optional favicon images

Place these files in `static/images/disablejs/` (Hugo serves them under /images/disablejs/):

- sy.png
- hn.png
- go.ico
- gm.png
- cgpt.png
- fes.png
- az.ico
- rd.png
- iw.png
- gr.png
- nx.ico
- yt.ico
- ftx.png

Missing icons fall back to the normal site favicon. No remote images are fetched.
Disable the demonstration with `params.enableDisableJsDemo = false` in hugo.toml.
